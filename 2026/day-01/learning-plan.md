# 90-Day DevOps Learning Plan

## Current Level

I am a Cloud Engineer with 3+ years of experience working on AWS and Linux production environments. I have hands-on experience in cloud operations, monitoring, incident management, infrastructure management, and automation. My goal is to strengthen my DevOps skills and become proficient in modern DevOps practices and tools.

## My Understanding of DevOps & Cloud Engineering

DevOps is a culture and set of practices that bridge development and operations through automation, collaboration, continuous integration, continuous delivery, monitoring, and infrastructure as code. Cloud Engineering focuses on designing, deploying, and managing scalable, secure, and reliable cloud infrastructure.

## Why I Am Starting This Journey

I want to deepen my DevOps expertise, improve my automation skills, gain hands-on experience with modern DevOps tools, and become capable of designing and managing production-grade cloud-native applications.

## 90-Day Goals

1. Build and deploy a production-ready application using Docker, Kubernetes, and AWS.
2. Create complete CI/CD pipelines using GitHub Actions and Jenkins.
3. Develop Infrastructure as Code projects using Terraform and automate cloud deployments.

## Core DevOps Skills to Build

1. Linux Administration & Troubleshooting
2. CI/CD Pipeline Design and Automation
3. Kubernetes & Cloud-Native Infrastructure Management

## Weekly Time Budget

* Weekdays: 2–3 hours daily
* Weekends: 4–6 hours daily
* Total Weekly Commitment: 18–25 hours

## Consistency Plan

* Complete at least one learning task every day.
* Practice hands-on labs instead of only watching tutorials.
* Document daily progress on GitHub and LinkedIn.
* Build real-world projects throughout the journey.
* Review weekly progress and identify improvement areas.

## Where I Want to Reach

By the end of 90 days, I want to confidently design, deploy, automate, monitor, and troubleshoot production-grade cloud infrastructure using AWS, Linux, Docker, Kubernetes, Terraform, and CI/CD tools while showcasing my work through GitHub projects and technical content.
